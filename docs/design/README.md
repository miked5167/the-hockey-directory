# Design Assets & Inspiration

This directory contains design inspiration, wireframes, and brand assets to guide the development of the Hockey Directory platform.

## 📁 Folder Structure

### `/inspiration/`
Place UI inspiration images and screenshots here to guide design decisions:

- **`/advisor-profiles/`** - Reference designs for advisor profile pages
  - Professional service profiles (LinkedIn, ZocDoc style)
  - Sports professional directories  
  - Trust-building layouts with credentials
  
- **`/search-results/`** - Directory and search result layouts
  - Service marketplace designs (ThumbTack, Bark, Upwork)
  - Filtered search interfaces
  - Card-based layouts with clear hierarchy
  
- **`/contact-forms/`** - Lead capture form inspirations
  - Multi-step form designs
  - Contact forms with trust signals
  - Mobile-first form layouts
  
- **`/subscription-tiers/`** - Pricing page and tier comparison designs
  - SaaS pricing tables
  - Clear feature differentiation
  - Upgrade/premium highlighting
  
- **`/mobile-layouts/`** - Mobile-responsive design examples
  - Mobile directory browsing
  - Touch-optimized contact forms
  - Mobile profile layouts

### `/wireframes/`
Place sketches, mockups, and wireframes here:
- Hand-drawn sketches
- Digital wireframes (Figma, Sketch exports)
- User flow diagrams
- Layout planning documents

### `/brand-assets/`
Brand identity and visual assets:
- Logo concepts and variations
- Color palette references
- Typography examples
- Icon sets and graphics
- Hockey-themed visual elements

## 🎨 Design Guidelines

### **Visual Theme**
- **Professional & Trustworthy:** Parents need to trust advisors with their children
- **Hockey-Focused:** Ice blue colors, hockey imagery, sports-appropriate tone
- **Mobile-First:** 60%+ traffic expected from mobile devices
- **Conversion-Optimized:** Clear CTAs, trust signals, minimal friction

### **Color Palette**
- **Primary:** Ice Blue (#0ea5e9) - professional, hockey-themed
- **Secondary:** Hockey Red (#dc2626) - accent color for CTAs
- **Success:** Green (#16a34a) - verification badges, success states
- **Warning:** Amber (#d97706) - alerts, featured highlights
- **Neutrals:** Clean grays for backgrounds and text

### **Typography**
- **Primary Font:** Inter - clean, modern, highly readable
- **Hierarchy:** Clear heading sizes, consistent spacing
- **Accessibility:** High contrast ratios, readable at all sizes

## 📸 How to Use This Folder

1. **Add Inspiration Images:** Save screenshots of designs you like to the appropriate subfolder
2. **Name Files Descriptively:** `advisor-profile-linkedin-style.png`, `pricing-table-saas-example.jpg`
3. **Reference in Development:** Claude will reference these images when building components
4. **Update Regularly:** Add new inspiration as you find good examples
5. **Document Decisions:** Note why certain designs work well for our use case

## 🔄 Design Process

### **Before Building New Components:**
1. Check this folder for relevant inspiration
2. Reference the PRD for business requirements
3. Consider mobile-first approach
4. Ensure subscription tier differentiation is clear

### **After Building Components:**
1. Take screenshots of completed work
2. Add to appropriate folders for future reference
3. Note what worked well and what could be improved
4. Update wireframes if design evolved during development

## 📱 Mobile Considerations

Given the high mobile traffic expected:
- **Touch Targets:** Minimum 44px for buttons and links
- **Thumb Navigation:** Important actions within thumb reach
- **Loading States:** Fast loading with skeleton screens
- **Offline Graceful:** Handle poor connections gracefully

## 🏒 Hockey-Specific Design Elements

### **Trust Building:**
- Verification badges prominently displayed
- Professional certifications highlighted
- Parent testimonials and success stories
- Clear contact information and response times

### **Subscription Differentiation:**
- **Basic:** Clean, professional appearance
- **Featured:** Golden highlights, star badges, priority placement
- **Premium:** Purple/crown styling, premium badges, top placement

### **Sports Aesthetics:**
- Ice blue primary colors (hockey rinks)
- Clean, athletic typography
- Action-oriented language
- Success-focused imagery
